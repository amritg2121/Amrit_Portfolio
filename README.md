# Portfolio website

Plain HTML, CSS and JavaScript. No build step, no install.

## Files
- `index.html`  all the text and links (edit this file)
- `style.css`   colours, fonts and layout
- `script.js`   menu, live previews and the contact form
- `images/`     profile photo and project screenshots
- `resume.pdf`  opened by the "Download resume" button

## Still worth checking in index.html
- The Kanban Task Manager "View code on GitHub" button points to your GitHub profile. Replace it with the repository link.
- The AmrFood card opens `food-delivery-website-lovat.vercel.app`. Make sure it is public and working.

## Put it online with Vercel
1. Create a GitHub repository and upload the files from INSIDE this folder (`index.html` must be at the top level of the repository, not inside another folder).
2. In Vercel choose Add New, then Project, and import the repository.
3. Set Application Preset to `Other`, leave Root Directory empty, and click Deploy.
